# نظرات کاربران سرویس‌ها / Service reviews

این پوشه فایل‌های JSON نظر کاربران را برای هر سرویس نگهداری می‌کند.
هر فایل با نام `<service-slug>.json` شناخته می‌شود و فقط زمانی توسط
سایت بارگذاری می‌شود که حداقل **۳ نظر تأییدشده** داشته باشد. این
آستانه با راهنمای Google برای رتبه‌بندی aggregate (نمای ستاره‌ای در
SERP) هم‌خوانی دارد و از فعال شدن snippet با تعداد کم نظر جلوگیری
می‌کند.

## اسکیمای فایل

دو فرم مجاز است:

### ۱) آرایه ساده

```json
[
  {
    "author": "علی محمدی",
    "datePublished": "2026-04-21",
    "rating": 5,
    "body": "خرید سریع، تحویل آنی و فعال‌سازی بدون دردسر بود.",
    "verified": true
  },
  {
    "author": "زهرا ر.",
    "datePublished": "2026-04-15",
    "rating": 4,
    "body": "اشتراک سالم بود، فقط راهنمای اولیه می‌توانست دقیق‌تر باشد.",
    "verified": true
  }
]
```

### ۲) با متادیتا (پیشنهادی)

```json
{
  "slug": "chatgpt",
  "reviews": [ /* همان آرایه بالا */ ]
}
```

## فیلدها

| فیلد            | اجباری | شرح                                                                 |
| --------------- | ------ | ------------------------------------------------------------------- |
| `author`        | خیر    | نام نمایشی نویسنده. در صورت خالی بودن «کاربر پی‌کارت» جایگزین می‌شود. |
| `datePublished` | خیر    | تاریخ ISO (YYYY-MM-DD).                                              |
| `rating`        | بله    | عدد صحیح ۱ تا ۵.                                                     |
| `body`          | خیر    | متن نظر فارسی. خط‌فاصله‌های جدید حفظ می‌شود.                          |
| `verified`      | خیر    | پیش‌فرض `true`. برای حذف از aggregateRating روی `false` تنظیم کنید.   |

## نکات مهم

- **نظر جعلی ممنوع.** Google در سال ۲۰۲۳ رهنمود review snippet را
  سخت‌گیرانه‌تر کرد؛ هر گونه گرید بدون پشتوانه واقعی منجر به اخطار
  دستی و حذف ستاره‌ها از SERP می‌شود.
- **حداقل ۳ نظر تأیید شده** برای فعال شدن aggregateRating نیاز است.
- فایل‌های این پوشه commit نمی‌شوند تا اکانتی برای جمع‌آوری بازخورد
  واقعی در dashboard اپراتور تعبیه شود؛ نمونه schema این مستند است.
- پس از افزودن فایل، با `npm run build` یا اجرای `vercel --prod` از
  بک‌اند، prerender فایل را می‌خواند و JSON-LD را با aggregateRating
  بازتولید می‌کند.
